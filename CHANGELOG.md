# Changelog

## 2.1.0 - 2026-11-22

### Added
- Dedicated **START** action at the top of the main menu.
- Separate **Select folder** action so the chosen library can be reused by START.
- START opens the folder browser automatically when no folder has been selected.
- README screenshots for the main menu, extension selector, scan preview and conversion progress.
- Automated tests for START menu priority and selected-folder reuse.

### Improved
- Main menu layout revised to make the primary action obvious.
- README shortened and refreshed with a compact visual tour and essential usage instructions.

## 2.0.0 - 2026-11-21
- Full-screen curses TUI, ASCII boot animation and SPDW Factory branding.
- Dependency LED, recursive folder browser, extension selector and ISO handling settings.
- Scan result preview, per-title progress, overall progress and batch logs.
- Source cleanup OFF by default with two explicit DELETE confirmations.
- Shared-track and playlist-aware source protection.
